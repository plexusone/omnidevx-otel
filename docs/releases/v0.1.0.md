# omnidevx-otel v0.1.0 Release Notes

**Release Date:** 2026-07-18

## Overview

Initial release of **omnidevx-otel**, the OmniDevX local telemetry plane:
a single loopback daemon that ingests OpenTelemetry metrics from AI coding
agents into the canonical
[omnidevx-core](https://github.com/plexusone/omnidevx-core) event store,
serves a read-only query API over it, and ships provisioned Grafana
dashboards.

The motivating problem: coding agents' local session history is subject to
retention limits, so token and cost history is permanently lost without
live capture. This daemon makes capture durable while keeping the JSONL
event store as the single source of truth — the service owns no data.

## Highlights

- **OTLP ingest** — `POST /v1/metrics` converts Claude Code
  (`claude_code.token.usage`, `claude_code.cost.usage`) and Codex CLI
  metrics into `ai.usage.recorded` events with otel-mode provenance.
  Retried exports deduplicate via deterministic event IDs. `POST /v1/logs`
  is acknowledged and discarded: prompt-bearing bodies are never stored.
- **Query API** — `GET /api/series?metric=tokens|cost|activity|commits`
  with day/week buckets, `since`/`until` bounds, and an optional
  collection-mode filter; aggregated on demand from the store, nothing
  cached authoritatively.
- **Grafana** — provisioned Infinity datasource plus a four-panel
  dashboard: tokens/day, cost/day, session activity, and weekly
  AI-assisted commit share.
- **Stdlib only** — OTLP JSON encoding by design
  (`OTEL_EXPORTER_OTLP_PROTOCOL=http/json`); no protobuf or gRPC
  dependencies. Loopback bind; no data leaves the machine.

## Installation

```bash
go install github.com/plexusone/omnidevx-otel/cmd/omnidevx-otel@v0.1.0
omnidevx-otel -person person:you
```
